# GrowLab release verification worksheet

This worksheet records test evidence for the October 18 sprint. It is not a production release approval.

## Acceptance gates

- [ ] Java 17 Maven verification passes on the exact reviewed commit.
- [ ] PostgreSQL 16 and Flyway migrations pass on a clean test database.
- [ ] Docker image builds and production JAR passes health checks.
- [ ] Authentication and role boundaries have negative tests.
- [ ] Customer data cannot be accessed across accounts.
- [ ] Signed internal webhook rejects invalid events and duplicate processing.
- [ ] Secrets are not committed; external integrations are disabled without configuration.
- [ ] A rollback and restore rehearsal is documented.

Keep failed checks unchecked and link the relevant CI run or issue before acceptance.
